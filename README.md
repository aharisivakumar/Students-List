# 🎓 Student Management System

A simple **Student Management System** built using **React.js**.
This project allows users to add students, display the student list, and manage favourite students using React `useState` and `useContext`.

## 🚀 Features

* Add new students using a student form
* Display students in a Student List
* Add students to Favourite Students
* Remove students from Favourite Students
* Automatically update the Student List when a favourite student is removed
* Share student data between components using `useContext`
* Manage application state using `useState`
* Responsive and simple user interface

## 🛠️ Technologies Used

* React.js
* JavaScript
* HTML
* CSS / Tailwind CSS
* React Hooks

  * `useState`
  * `useContext`
